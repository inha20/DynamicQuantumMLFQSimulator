# 진행 기록

AI(Claude)가 작성한 초안이며 사람의 검토 전이다.

이 기록은 2026-11-08에 시작했다. 그 전에 만든 시뮬레이터, 실험, 결과, 분석 노트, README의 본문(`mlfqsim/`, `experiments.py`, `results/`, `docs/analysis.md`, README)은 이 기록이 만든 것이 아니다. `experiments.py`와 `results/`는 그대로 두었다. `mlfqsim/sim.py`에는 옵션 `Config.defer_requeue`(기본 `False`) 하나를 더했고 기본 동작과 저장된 결과는 그대로다(아래 측정 도구 검증 줄). README의 결과 문장 19개는 결과 CSV와 어긋나 고쳤고(고치기 전 문장은 `refs/claims-ledger.md`의 '고침' 행에 있다), `docs/analysis.md`는 본문을 그대로 두고 맨 위에 안내만 더했다. README에서 바꾼 곳은 아래 기록의 해당 날짜 줄에 적는다.

## 작업 방식

- 이 저장소의 기존 결과는 **탐색적 결과**다. 실험을 하기 전에 가설과 분석 계획을 적어 두지 않았다. 새 문서는 주장마다 확인 수준을 붙이고 새롭다는 주장을 하지 않는다.
- 새 정책의 구현(예: demotion 판정을 quantum과 분리한 변형)과 확인용 실행은 사전 분석 계획의 동결(사람의 승인) 전에는 하지 않는다.
- 사람이 정해야 닫히는 항목은 하지 않고 막힌 것으로 기록한다.
- 이 작업은 같은 방법을 쓰는 다른 저장소(DeadlockConditionRedefinitionAndPrevention)의 연구 상태에 이 프로젝트를 맞추는 일의 한 단계다. 배경은 그 저장소의 진행 기록 중 "다른 프로젝트 세 개의 평가(2026-11-08)"에 있다.

### 확인 수준

| 표기 | 의미 |
|---|---|
| A | 본문(전문 또는 해당 절)을 직접 읽고 확인 |
| A− | 원문의 일부 발췌만 확인 |
| B | 서지, 초록, 공식 문서 페이지에서 확인(본문 미확인) |
| C | 교과서, 강의노트, 블로그 등 2차 자료로만 확인 |
| D | 다른 문헌의 참고문헌 목록에서 존재만 확인 |
| X | 확인 실패 또는 미확인 |
| V | 이 저장소의 코드로 재현할 수 있는 자체 계산. 문헌 근거와 종류가 다르며 증명이 아니다. 모델과 범위를 함께 적는다 |

C 이하는 논증의 전제로 쓰지 않고 단서로만 쓴다.
